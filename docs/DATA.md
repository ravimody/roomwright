# Data reference

Generated by `tools/make_docs.py` from `schema/*.schema.json`; edit the schema, not this file.
Check a room with `uv run ../../tools/validate_room.py` (schema plus consistency checks). Builder-specific catalog keys
(sofa `arms`, lamp `shade`, …) are described in the household's `builders/README.md` and in docs/MODELING.md; any catalog key can be overridden per layout item.

## room.json

## catalog.json

Item types: real dimensions (metres) plus how to draw them: a core model (box, parts, glb, mat, roundRug) or a household builder (builders/*.py and .js next to rooms/). Catalogs merge in order: the engine's shared/catalog.json (generic entries), the household's catalog.json, the room's catalog.json; later entries win.
